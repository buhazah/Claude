# 5. Autonomy is earned in shadow, per action type

Status: proposed

## Context

Nobody hands an unproven system £50k/month, and they are right not to. The
usual answer — ship with conservative defaults and widen over time — has no
evidence behind the widening. It is a feeling about how well it seems to be
going.

Phase 11 established the discipline that answers this: a change is answerable
with "eleven cases improved and two broke" against a committed baseline, not
with an impression.

## Decision

**Shadow mode first, always, for every new action type.**

The full loop runs — ingest, signals, diagnosis, proposals, mandate checks —
and stops at the decision record. Nothing touches Meta. Each proposal persists
what it *would* have done and what it expected. Weeks later the outcome is
known and each proposal is scored.

Autonomy is then granted **per action type**, on evidence, through tiers:

| Tier | Behaviour | Entry |
|---|---|---|
| 0 Shadow | proposes only | default, always |
| 1 Notify | executes, tells you after | ≥30 proposals, ≥80% correct |
| 2 Mandated | executes within the envelope | 30 days at tier 1, zero breaches, customer agrees |
| 3 Broad | wider limits, weekly reporting | 90 days at tier 2, positive measured outcome |

Demotion to tier 0 is automatic on any breach, any outcome below threshold, or
any customer request. Earning back means going through the tiers again.

Shadow never switches off — live actions run alongside shadow proposals as a
permanent control.

## Alternatives rejected

**Ship conservative and widen by feel.** No evidence, and the widening happens
when someone is impatient rather than when the data supports it.

**Simulation against historical data.** No counterfactual for actions never
taken, and it cannot model how the auction responds.

**Autonomy per client rather than per action type.** Hides the variance that
matters: budget shifts might be 95% correct while pausing is 45%, and those
deserve different authority.

## Consequences

- The first version is **safe by construction** — it cannot spend, because the
  code path does not exist.
- Sales gets a sentence nobody argues with: *"143 proposals over 60 days; if
  executed, blended CAC would have been 11% lower. Six would have been wrong;
  here they are."*
- Labelled training data is generated by operating.
- **Cost:** 60+ days before any autonomy, per action type. That is the price of
  the evidence, and the alternative is asking a customer to take it on trust.
- **Limitation, stated honestly:** an unexecuted proposal has a *counterfactual*
  outcome, which is an estimate. Where stakes justify it, resolve with a real
  holdout. Where they do not, report the estimate as an estimate.
